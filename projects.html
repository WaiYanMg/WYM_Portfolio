A small responsive website created using HTML, CSS, and JavaScript as part of a web development assignment at CCT College Dublin. It presents essential information about a clinic’s services, background, and contact options.

The project inspired my idea for a booking-based website that could be adapted for restaurants, salons, or barbers. This version was deployed on Amazon Web Services (AWS EC2) for cloud testing and hosting practice.

In my portfolio website, I expanded on this concept by integrating EmailJS for direct contact and message delivery via email.
